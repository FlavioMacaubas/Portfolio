# Portfolio — Flávio Macaúbas

Este repositório é o hub do meu portfólio técnico com foco em **Data Engineering + IA aplicada**.

## Objetivo
Apresentar projetos com contexto de negócio, arquitetura, stack, decisões técnicas e resultados.

## Trilhas principais
- Engenharia de dados: pipelines ETL/ELT, tratamento e modelagem
- IA aplicada: assistentes, RAG e automações orientadas a contexto
- Analytics: exploração, visualização e comunicação de insights
